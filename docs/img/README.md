# Capturas

GIFs que usa el README principal. Grabados con Playwright sobre una empresa ficticia (Pyme Demo SRL), sin datos
reales de clientes. 1280×720 escalado a 960 px, 12 fps.

| Archivo | Qué muestra |
|---|---|
| `dashboard.gif` | Ingresos, gastos, balance, movimientos fijos pendientes, saldo por cuenta y tendencia mensual |
| `transferencia-monedas.gif` | Transferencia USD → ARS con el monto acreditado calculado por cotización |
| `saldo-insuficiente.gif` | Gasto rechazado con el mensaje completo de saldo insuficiente |
| `asistente-ia.gif` | Pregunta en lenguaje natural y respuesta por categoría |
| `cuarentena.gif` | Revisión y aprobación de un movimiento importado por CSV |
| `nueva-transaccion.gif` | Alta de un gasto |
| `movimientos-fijos.gif` | Confirmación de un gasto fijo vencido |

Para regrabarlos: proyecto `portfolio-grabaciones` (`node asistente/grabar.js`).
